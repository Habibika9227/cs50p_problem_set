# CS50P – Problem Set Solutions 🐍

This repository contains my solutions to problems from **CS50’s Introduction to Programming with Python (CS50P)**.

## 📚 About the Course
CS50P is a course by Harvard University that teaches the fundamentals of Python programming, including:

- Functions
- Conditionals
- Loops
- Exceptions
- File I/O
- Regular Expressions
- Object-Oriented Programming (OOP)

- Understanding core Python concepts
